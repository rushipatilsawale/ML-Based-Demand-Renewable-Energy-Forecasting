# ML-Based Demand & Renewable Energy Forecasting

## Project Overview

A full-stack machine learning system for short-term electricity demand
and renewable energy supply forecasting.

The system will:

- Forecast electricity demand
- Forecast solar and wind renewable supply
- Estimate forecast uncertainty
- Simulate storage-vs-backup dispatch decisions
- Calculate cost and CO2 impact
- Provide an interactive dashboard
- Explain model predictions using SHAP

## Project Architecture

Raw Data
→ Data Pipeline
→ ML Models
→ FastAPI Backend
→ Database
→ Frontend Dashboard
